📊 综合诊断结论
按照 task.txt 四个原因的评估：

原因	判断	权重
1. state 缺失物体信息	✅ 主因 — state 只有 robot 姿态	🟡🟡🟡
2. kNN 跨阶段	✅ 关键 — 64% 邻居来自不同阶段	🟡🟡🟡
3. GMM 过拟合	⚠️ 部分 — BIC 并非一直下降	🟡
4. LIBERO 真多峰	❌ 不是 — 是 state 信息不足导致的伪多峰	
根因: kNN 基于 robot 姿态 (15D) 检索邻居 → 找到相同"机器人姿势"的帧，但这些帧对应不同任务阶段 → 不同阶段 action 不同 → GMM 识別出多个峰 → 这是 p(a|robot_state) 的多峰，而非论文的 p(a|observation) 多峰。
