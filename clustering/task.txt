一、应该使用哪个 LIBERO 数据集

LIBERO包含四个benchmark：

LIBERO_OBJECT
LIBERO_GOAL
LIBERO_SPATIAL
LIBERO_10

如果是第一次做分析：

建议：

LIBERO_OBJECT

原因：

任务数量适中
数据量足够大
操作对象丰富
被论文广泛使用

而且这篇论文Table 4也专门报告了 LIBERO Object 的结果。

二、使用什么作为 Observation

不要直接用 RGB。

因为：

img1.shape=(128,128,3)
img2.shape=(128,128,3)

欧氏距离没有意义。

LIBERO原始数据里通常包含：

robot_states

例如：

obs["robot0_joint_pos"]
obs["robot0_eef_pos"]
obs["robot0_eef_quat"]
obs["gripper_qpos"]

这些才是真正的状态。

构造：

state_feature = np.concatenate([
    joint_pos,
    eef_pos,
    eef_quat,
    gripper
])

例如：

(14,)

或

(20,)

维度。

三、分析流程
Step1 提取数据

输入：

LIBERO hdf5

输出：

states
actions

形状：

states.shape
=
(N,Ds)

actions.shape
=
(N,Da)

例如：

(100000,14)

(100000,7)
Step2 PCA降维状态

输入：

states

输出：

states_pca
(100000,10)

代码：

from sklearn.decomposition import PCA

pca = PCA(n_components=10)
states_pca = pca.fit_transform(states)
Step3 建立kNN

输入：

states_pca

输出：

knn索引

代码：

from sklearn.neighbors import NearestNeighbors

knn = NearestNeighbors(
    n_neighbors=300,
    metric="euclidean"
)

knn.fit(states_pca)
Step4 随机采样Observation

输入：

states_pca

输出：

100个中心状态

代码：

sample_ids = np.random.choice(
    len(states_pca),
    100,
    replace=False
)
Step5 获取邻域Action

对于每个状态：

o*

寻找：

300 nearest neighbors

代码：

dist, idx = knn.kneighbors(
    states_pca[i].reshape(1,-1)
)

local_actions = actions[idx[0]]

输出：

(300,7)
Step6 PCA压缩Action

输入：

local_actions

输出：

local_actions_pca
(300,3)

代码：

act_pca = PCA(3)
local_actions_pca = act_pca.fit_transform(
    local_actions
)
Step7 GMM判断峰数

这是核心。

输入：

local_actions_pca

输出：

最佳峰数K*

代码：

from sklearn.mixture import GaussianMixture

bic_scores = []

for k in range(1,6):

    gmm = GaussianMixture(
        n_components=k,
        random_state=0
    )

    gmm.fit(local_actions_pca)

    bic_scores.append(
        gmm.bic(local_actions_pca)
    )

best_k = np.argmin(bic_scores)+1
Step8 统计

保存：

all_best_k

例如：

[1,1,1,2,1,1,3,...]

统计：

from collections import Counter

counter = Counter(all_best_k)

print(counter)

输出：

{
1:84,
2:13,
3:3
}
